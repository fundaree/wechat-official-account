# 微信公众号接入示例

一个最简单的微信公众号消息收发服务器（Flask）。公众号收到粉丝的文字消息后，会自动回复。

## 重要前提

1. **接的是「微信公众号」（服务号或订阅号），不是个人微信号。** 个人微信号挂机器人会被微信封号，不要尝试。
2. **它接的不是 Muse 本人。** Muse 没有对外开放的 API，外部程序没办法调用 Muse，所以代码里的 `chat_reply()` 只是一个占位函数，默认回一句固定提示。想让公众号自动智能回复，把 `chat_reply()` 换成你自己的大模型接口调用（代码里有注释示例）。

## 需要准备

- 一个微信公众号（服务号或订阅号）
- 一台能被公网访问的服务器 + 一个域名（需要 80 或 443 端口）
- Python 3

## 运行

```bash
pip install -r requirements.txt
WECHAT_TOKEN=你的token python 微信公众号接入示例.py
```

## 在公众号后台配置

1. 进入公众号后台「设置与开发 → 基本配置」，拿到 token，填到环境变量 `WECHAT_TOKEN`（不要把真实 token 写进代码或提交到公开仓库）。
2. 把「服务器地址（URL）」填成 `https://你的域名/wechat`，令牌填同一个 token，消息加解密方式选「明文模式」，提交并启用。

## 测试

给公众号发一条文字消息，能收到自动回复就说明接通了。
